Basic Calculator

A simple, stylish, and responsive Basic Calculator built using HTML, CSS, and JavaScript.
This project performs basic arithmetic operations like addition, subtraction, multiplication, and division with smooth UI design and keyboard support.

🚀 Features

  ➕ Basic Operations: Addition, subtraction, multiplication, division

  💻 Keyboard Support: Use your keyboard to input numbers and operations

  🧼 Clear & Delete: AC to clear all, CE to clear entry, ⌫ to delete the last digit

  🖥️ Responsive Design: Works seamlessly on mobile and desktop

  ✨ Modern UI: Gradient background, rounded buttons, hover animations

🧰 Technologies Used

  HTML5 – Structure of the calculator

  CSS3 – Styling with gradient background and responsive grid layout

  JavaScript (ES6) – Logic for calculator operations and keyboard interaction

🧩 Keyboard Shortcuts
     Key	              Function
     0–9              	Enter numbers
     + - × ÷           	Perform operations
     .                 	Decimal point
     Enter / =         	Calculate result
     Esc              	Clear all
     Backspace         	Delete last digit
